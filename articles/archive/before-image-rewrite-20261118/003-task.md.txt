# 第3章：增加分类汇总与 Markdown 报告

## 一、本章学什么，交付什么

这一章集中学习增量需求、已有代码、独占创建输出。我们完成的任务是：扩展 --output，生成 report.md 并拒绝覆盖。不用真实账单，避免把私人收支交给尚未核实的流程。

## 二、先看任务路线

```mermaid
flowchart TD
 A[有效输入] --> B[分类和总额汇总]
```

导出前先验证完整输入；输出路径已存在时停止。图中的拒绝分支既要返回非零退出码，也要保证旧文件没有变化。

## 三、准备本章输入

先完成第一章环境检查。本章只用 Python 标准库，不重复安装 CLI 或扩展。新建独立目录，放入合成 sample.csv；复制上一章 ch02 的 ledger.py，本章仅修改副本。本次真实运行的交付文件在 [本章素材目录](../assets/recordings/20261118T133012Z/A003/README.md)，也可先跟着提示词完成，再与记录对照。

## 四、把任务交给 Codex

```text
只操作当前练习目录，不访问其他项目、账号配置或私人文件。只用Python标准库，不安装依赖，不使用浏览器、桌面控制或网络工具。先简述计划，再真正执行命令，中文回复简短。不能运行时如实说明，不伪造输出。已有目标不要覆盖。

读取已有ledger.py和sample.csv，在本章副本增量增加分类汇总以及可选--output report.md。不指定输出则打印，指定输出用排他创建，目标已存在返回非零且不改旧文件。全部输入验证后才写文件。先新建report.md并读回，再重复执行验证拒绝覆盖、报告字节和输入字节不变。分类餐饮50.00、交通12.00。保留命令输出，最后列出改动和实际检查。只修改ledger.py并新建report.md。
```

这里限定目录是为了减少无关修改，要求先阅读则让计划有输入依据。文字要求不能代替操作系统权限，实际授权仍需检查。

在复制后的本章目录运行：

```sh
python3 ledger.py --input sample.csv --output report.md
```

手工预期为收入5000.00、支出62.00、结余4938.00。餐饮支出50.00，交通支出12.00。这个预期来自四条合成记录相加，不是某次模型运行的引文。

逐行读代码时先找输入解析，再找累加位置，最后找输出。金额不用浮点数，是为了避免二进制浮点表示给十进制计算带来额外误差。日期采用 ISO 格式；非法类型、负金额或超过两位小数会指出错误行。空表允许输出零值，但缺列应失败。

## 五、追问和纠错怎么写

```text
先暂停修改。说明当前结果与预期的哪一项不符，给出输入行和代码依据。只修复已确认的问题，保留失败样例，不修改预期来适配错误结果。修复后重新检查全部相关项。
```

若模型提出安装第三方库，先要求解释标准库无法完成的部分。若只是路径错误，回到工作目录核对，不要扩大到整个磁盘。已有输出应换新名字保存，不能为了继续而自动覆盖。

## 六、迁移练习与验收

```text
我要换用自己的合成数据。请先列出字段、金额、日期及输出约束中需要确认的问题，等我确认后再改。保留旧版本和测试输入，解释每一项新行为。
```

先自己算一组小数据，再观察程序。原件不变、金额一致、错误能定位、输出可重开才算交付。第四章再运行配套的 python3 -m unittest -v；本章先检查自己的交付条件。
