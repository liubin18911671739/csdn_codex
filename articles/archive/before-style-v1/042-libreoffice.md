# 用 LibreOffice 替代付费办公软件 从安装到文档兼容检查

验证状态：macOS 上已观察过界面字体回退及绿色背景设置；Windows 全流程待实测。本篇不保证任何复杂 Office 文件完全兼容。

## 从一份副本开始
开源替代的关键是迁移后仍能完成工作。先复制一份 Word 文档、一个 Excel 表和一份 PowerPoint 演示，原文件另存。涉及宏、外部连接、嵌入字体或复杂动画的文件单独列入测试清单。

## 获取与安装
从 https://www.libreoffice.org/download/download-libreoffice/ 获取适用 Windows 的版本。记录下载日期与版本号，按官方安装提示完成安装；不要在首次安装时批量改写所有文件关联。

先打开 Writer 创建一份空文档，输入中英文，保存为 ODT，再另存一份 DOCX。重新打开两份文件，核对文字、标点和段落。出现格式兼容提示时先阅读提示，再决定保留哪种格式，原始文件不要覆盖。

## 设置舒适的编辑背景
在工具菜单中打开选项，查找“外观”或“应用程序颜色”。不同版本项目名称可能变化。查找文档背景与应用程序背景，将页面颜色设为 `#CCE8CF`，周围编辑区设为 `#B7D7BB`。如果启用了背景图片，先关闭该效果。

这属于应用显示偏好；不要为了护眼而直接修改文档页面填充色。用打印预览确认纸面效果，必要时导出 PDF 检查。颜色偏好不能代替休息和合适的屏幕亮度。

## 三类兼容检查
Word：检查总页数、标题级别、目录、脚注、表格跨页和批注。对照原软件导出的参考 PDF；仅页数相同不能证明内容相同。

Excel：重点检查日期、货币、公式结果、图表、筛选及外部数据。宏或专有函数不能只凭文件成功打开就视为迁移完成。记录输入及预期结果，重新计算后逐项比对。

PowerPoint：检查字体替换、文本框溢出、图片裁切、动画和演讲者备注。逐页查看并实际播放一遍，交付 PDF 时另行检查链接及版式。

## 迁移决定和回退
建立一张兼容记录：文件、原版本、替代版本、问题、影响、处理结果。关键问题未解决时继续保留原工具处理该类文件，普通文件先迁移。原文件与参考 PDF 保存在独立备份位置。

若中文菜单异常，先记录系统与 LibreOffice 版本，查官方已知问题；不要把 macOS 特定的字体修复配置直接复制到 Windows。

## 来源与验证
官方帮助：https://help.libreoffice.org/ 。发布前核对当时 Windows 版本菜单、安装流程及三类测试样本，采集脱敏截图。
