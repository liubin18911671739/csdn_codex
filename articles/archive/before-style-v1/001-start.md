# 开始之前 配好 Windows AI 工作环境并完成第一个任务

验证状态：Windows 待实测。适用 Windows 11；菜单名称需按安装版本核对。

## 要完成什么
用 AI 将一段杂乱的项目记录整理为待办清单，保存为 Markdown 文件。第一步先学会说明任务和验收，不急着连接真实邮箱或网盘。

## 准备环境
准备浏览器、文本编辑器和一个可使用的 AI 账号。先使用账户当前已有功能；本案例不需要 API 密钥，也不要求购买订阅。模型、地区和账号会影响功能可用性，以账户页面为准。

如要执行后面的 Python 案例，从 https://www.python.org/downloads/windows/ 获取官方安装程序。安装后打开新的 PowerShell 窗口，执行 `py -3 --version`。出现版本号才继续。命令找不到时检查安装程序和 Python Launcher；不要从陌生网站下载同名修复工具。

## 第一个任务
在聊天框输入以下完整任务：

> 请将下面的合成记录整理成 Markdown 待办清单。每行包含任务、负责人、截止时间；未知信息写“待确认”，不要自行猜测。记录：周五前整理图片，负责人小林；报告由小周负责，尚未确定日期；还有一次资料备份，负责人和日期都未定。

预期得到三项待办。逐项对照原文：图片负责人小林，报告负责人小周，备份负责人待确认。周五缺少具体年月日，因此不能让模型擅自换成某个日期。

打开记事本，新建文档，粘贴核对后的结果。另存为 `first-task.md`，选择所有文件类型和 UTF-8 编码。用资源管理器开启文件扩展名显示，检查没有保存成 `.md.txt`。

## 从聊天走向执行
第二次任务可要求 AI 编写脚本，但先要求它说明输入位置、是否联网、哪些文件会变化，以及如何恢复。让它先在 `examples` 的合成文件上操作。不能把“看起来对”当成执行成功；至少打开输出、核对数量和内容。

不要直接上传身份证、未发表研究数据或工作机密。需要处理时先做脱敏，并确认使用服务的权限和数据要求。

## 验收与排错
合格成果是一个可以重新打开的 UTF-8 文件，包含三项任务，且没有新增负责人和日期。出现乱码时重新按 UTF-8 保存；遗漏项目时要求模型指出原文对应位置再修订。
